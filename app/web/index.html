ⓘ Reddit API Erişimi — Yardım
REDDIT API KAYIT REHBERİ · EKİM 2026

Reddit'in 2026 API politikaları sıkılaştı. Önce yetkili API erişimine başvurmanız gerekebilir. Her hesaba otomatik Client ID ve Secret verilmez.

  1. Reddit hesabınızla oturum açın.
  2. Responsible Builder Policy ve Data API Terms sayfalarını okuyun.
  3. Uygulamanızın araştırma amacını açıklayarak Reddit destek / Data API erişim formundan başvurun. Uygun şartlar ve izinler gerekli olabilir.
  4. Reddit izin verdiyse reddit.com/prefs/apps üzerinden uygulama oluşturun. Bu sayfa yeni hesaplarda izin ekranına yönlendirebilir.
  5. Uygulama türünüzde gerekiyorsa client ID ve client secret değerlerini alın. Programdaki alanlara yazın; User-Agent'i uygulamanıza özel tutun.
  6. Ayarları Kaydet ardından Bağlantıyı Test Et seçeneğini kullanın. Token alınsa bile veri kullanım izni ayrıca geçerli olmalıdır.

30 Eylül 2026 tarihli Reddit duyurusuna göre Data API uygulamaları Developer Platform'a taşınıyor. 2027 geçiş takvimini kontrol edin. Mevcut API desteği ve yeni uygulama onayı zamanla değişebilir.

Bu uygulama erişim kısıtlarını aşmaz, API engellerini baypas etmez. Reddit verileriyle model eğitimi veya ticari kullanım ayrıca izne tabi olabilir.
